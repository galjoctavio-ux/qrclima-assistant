# Mensaje inicial para el chat de finanzas

Ayúdame a revisar registros financieros de QRclima usando `$qrclima-revisar-finanzas` y mi perfil privado seleccionado. Usa lecturas autorizadas y distingue venta, cobro, deuda, gasto y utilidad. Explica los vínculos y las evidencias que falten sin inventar fechas, pagos, costos o facturas. Este chat comienza en modo de lectura: propone las correcciones necesarias, pero no registra pagos, borra movimientos, emite CFDI ni mueve dinero.
