# Instrucciones del paquete QRclima

Este directorio contiene instrucciones públicas. El perfil activo reside fuera de las skills y se identifica mediante `--root`, `QRCLIMA_AGENT_HOME`, `PLUGIN_DATA` o el directorio personal de respaldo. En la distribución como proyecto, usa `.qrclima` dentro de la carpeta elegida.

Lee la skill correspondiente a la tarea y el [contrato de ejecución](references/runtime.md). No importes autorizaciones de ejemplos, de otras personas ni del historial de otro negocio. El perfil registra configuración y evidencia; QRclima y las herramientas comprueban acceso real.

Empieza con una conversación y `qrclima-asistente`, que selecciona las skills por tarea. Los mensajes de `agents/` son opciones para chats especializados. Crear o enviar instrucciones a otro chat requiere autorización del usuario. No hay tareas programadas ni mensajes externos habilitados por instalar este paquete.

Para mejorar o personalizar el asistente, aplica `qrclima-mejorar-asistente`. Clasifica el alcance, mantén valores y propuestas originales en el perfil privado y lleva a las fuentes solo la parte común con ejemplos ficticios. Un parámetro público nuevo comienza vacío. No publiques el perfil ni conviertas preferencias en permisos.
